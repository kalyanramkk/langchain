# Langchain Assignments

This project contains the assignment Jupyter notebook files and the test prompts for Prompt Evaluator Agent. Below are the contents of this project

- Prompt Quality Evaluator Agent -  Prompt_Quality_Scoring_Agent.ipynb
- Travel Agent Chatbot - Travel_Agent_Chatbot.ipynb
- Prompt Quality Agent Test Promps - assignment-test-prompts.docx

# Description

- Prompt Quality plays a crucial role in the output that is generated by an LLM Model. To simplify this important task, I have built and agent that will take an input prompt and score the quality of the prompt based on various criteria. This agent also provides suggestions for improvement of the prompt

- Travel Agent Chatbot takes the input of destination and number of days to plan and generates the details of the vacatio. The persona for this agent is tagged to answer only Travel related questions. If any other topic is prompted then it will respond a static message

# Prompt Quality Evaluator Agent 

- Agent Input

  - The input prompt
    
- Agent Output
  - Final score (0–10)
  - Scores for each quality criterion
  - Short explanation
  - 2–3 suggestions to improve the prompt
