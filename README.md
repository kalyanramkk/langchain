# Prompt Quality Evaluator Agent
This project contains the code for Prompt Qaulity Evaluator Agent


# Description
Prompt Quality plays a crucial role in the output that is generated by an LLM Model. To simplify this important task, I have built and agent that will take an input prompt and score the quality of the prompt based on various criteria. This agent also provides suggestions for improvement of the prompt
